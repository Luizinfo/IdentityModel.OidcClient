# Contributing

Open an issue at [GitHub Issues](https://github.com/Luizinfo/IdentityModel.OidcClient/issues) before substantial changes. Pull requests should target `net10.0`, preserve the public `IdentityModel.OidcClient*` namespaces and assemblies, include focused tests, and pass the Release build and test suites. By contributing, you agree that your work is licensed under Apache-2.0.
